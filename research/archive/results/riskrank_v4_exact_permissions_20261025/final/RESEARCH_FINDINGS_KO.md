# RiskRank 수정 버전: 실제 권한 계약·Bayesian 갱신·일관된 질의 모형

이전 V3 결과·예측 잠금은 보존했다. 수정 버전은 실제 도구 허용 목록을 포함하는 새 입력 해상도이며, 비교군도 똑같은 정보를 받는다. 기존 15% 개선·40% 비용 절감·Brier 비열등 한계 .01은 바꾸지 않았다.

초기 예측 SEEN: 기준선 0.100074, RiskRank 0.097073, 상대 개선 3.00%.
업무 전이 OOD: 기준선 0.169368, RiskRank 0.169368.
초기 1~10회 Bayesian 갱신: 모든 강한 비교군 우위=False.
추가 진단비용 절감률: 정의 불가: 최적 고정 비교군 자체가 0비용. 비용0을 40% 개선으로 표시하지 않는다.

핵심 판정: {'cold': 'NOT_SUPPORTED', 'online': 'NOT_SUPPORTED', 'acquisition': 'UNDEFINED_ZERO_COST_COMPARATOR'}.

실행 분모는 초기 평가4,608 + 이력2,304 + 질의 표적192 =7,104회다. 진단 프로브와 정책 영수증은 별도 단위이며 독립 표적에 합산하지 않는다.
서로 다른 모델·입력 계약·업무 모집단의 사고율을 합산하지 않는다. 가상 상태 손실이며 실제 고객 사고율이나 보험료가 아니다.

원래 진단 시도는192개 중4개 표적만 완료됐고, 정상/적대 표적의 진단 ID 충돌로 중단됐다. 해당 원시 기록과 미확정 영수증은 보존했다. 위 진단 결과는 origin_target_id를 포함한 별도 R2 모집단192개로 계산했으며 원본의 완료 상태를 소급 변경하지 않는다.
