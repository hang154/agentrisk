# CS Reliability 연구 — 사용자 지정 시점 종료 결과

2026-10-16 사용자 지시로 신규 실행을 중단했다. 원래 전체 계획의 완료가 아니라
**USER_STOPPED_PARTIAL_STUDY**다. 기존 증거·Forecast Lock·오라클을 변경하지 않았다.
기본 성과 단위는 사용자 승인에 따라 고객 건 실행이며, 전체 Root 완료는 보조 지표다.

26,389개 원장 파일이 있다는 것은 26,389개 적격 성공 표본이라는 뜻이 아니다.

중단 요청은 재전송하거나 성공·실패·0손실로 대체하지 않았다.
후속 조건부 Phase B·Tail·권한 선택 실험은 완료하지 않았다.

단순 안전 차단은 업무 성공이 아니다. 이관 성공은 가상 큐 접수·상태 확인이며

## 사전 예측: 수렴과 정확도는 다르다

F0/F1 각각 네 모형은 수렴 게이트를 통과했다. 점수는 결과가 알려져 있고
두 시드가 완결된 일부 Blind Root×정책 셀에 한해서 산출했다.
원래 잠금의 Root 단위 예측을 고객 건 예측으로 소급 변경하지 않았다.

| 예측 대상 | F0 모형 / Beta Brier | F1 모형 / Beta Brier |
|---|---:|---:|
| 정상 업무 Root 완료 | 0.06063 / 0.06053 | 0.05998 / 0.06020 |
| 잘못된 제안 | 0.33678 / 0.28658 | 0.26471 / 0.27455 |
| 잘못된 제안의 통과 | 0.21811 / 0.23662 | 0.17123 / 0.23398 |
| 잘못된 상태 변경 | 0.20652 / 0.14977 | 0.10310 / 0.14074 |

Brier는 낮을수록 좋다. F1의 위험 지표에는 유리한 관측이 있지만,
업무 효용 Log Loss는 모형 0.21713 / Beta 0.21633으로 조금 나쁘다.
모든 지표의 우월성·제품 승격을 주장하지 않는다. 중단·결측 선택편향과
부분 Blind 표본의 한계가 있어 전체 미관측 Stack 일반화 검증은 미완료다.

## 재현·보존 범위

이번 종료 집계는 원본 admission/result/oracle SHA 대조에 기반한다.
전체 원시 API를 별도 프로세스에서 다시 해석한 최종 독립 재현은 미완료다.
기존 NAS sealed archive의 실행 ID 합집합은 26,389개로 확인됐다.
별도 종료 아카이브와 보존 receipt에 원본 메타데이터·잠금·집계·분석 소스를 연결한다.
모델 가중치는 연구 증거 백업에 포함하지 않는다.

`CUSTOMER_CASE_RESULTS.json`, `PARTIAL_FORECAST_EVALUATION.json`,
`FINAL_STATUS.json`이 기계 판독 산출물이다. 원본 실험 FULL, 99% 업무 신뢰성,
고객 보험료 산정 완료, 실제 사람 승인 완료는 모두 주장하지 않는다.
