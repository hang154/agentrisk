# AgentRisk-CS V3 연구 결과 — 완료된 실행과 미충족 연구 목표

2026-10-12. V2 원본은 변경하지 않았다. 신규 V3 실제 모델 실행은 2,600회다:
Gemma B0–B3 1,600회, Qwen 기준선 400회, GPT Anchor 100회/Blind 300회,
Gemma 고정 도입정책 200회. 추천정책은 100개 신규 Root 모두 자동 위임을
보류했으므로 추가 200회 모델 호출을 만들지 않았다.

## 완료 판정

자동 실행과 분석은 종료됐으나 G0–G4 연구 완료는 **false**다.
Gemma의 300초 HTTP 타임아웃 65건이 63개 Root×정책 셀에 영향을 줬다.
B/C의 1,200개 Root 셀 중 1,137개만 독립 수용됐다. 누락은 무사고·성공이 아니다.
G1 업무 오라클 인증과 G4 전향적 정책 비교 실행은 통과했다. G0/G2/G3는
미통과다. 고객 Shadow(G5), 실제 보험 인수자료(G6)는 확보되지 않았다.

## 권한·검증자 비교

표의 독립 단위는 Root×정책이다. 정상업무 완료는 두 시드 모두 정확해야 1,
위험 상태 변경은 두 시드 중 하나 이상이면 1이다. 따라서 에피소드 성공률이나
실제 고객 통화 사고율로 읽으면 안 된다. 정상·적대 상황이 층화된 합성 모집단이다.

| Gemma 조건 | 수용/예정 Root 셀 | 정상 완료/수용 정상 Root | 위험 상태 변경/수용 Root |
| --- | ---: | ---: | ---: |
| B0 전체 권한 + 기존 하드 게이트 | 182/200 | 28/87 | 93/182 |
| B1 최소권한 + 동일 하드 게이트 | 185/200 | 45/92 | 47/185 |
| B2 전체 권한 + GPT reviewer + 하드 게이트 | 191/200 | 39/94 | 61/191 |
| B3 최소권한 + GPT reviewer + 하드 게이트 | 179/200 | 41/87 | 29/179 |

이는 관측 수용분의 기술통계다. 누락 패턴과 분모가 다르므로 이 표만으로
통제의 인과효과를 확정하지 않는다. 업무별 동일 Root 페어드 차이·2,000회
bootstrap·누락 경계는 `AUTHORITY_CLOSED_LOOP.json`에 보존했다.
위험 상태 변경과 금전손실은 별개다. 예를 들어 B3에서도 위험 상태 변경은
관측됐지만 수용 Root의 가상 잔여 금전손실 합은 0이었다. 이를 무위험이라
해석하거나 보험료 0으로 환산하지 않는다.

## 미관측 스택 예측: 입증 실패

GPT Actor 실행 전 F0, 사전 선정 Anchor 이후 Blind 실행 전 F1을 잠갔다.
Anchor 50 Root와 Blind 150 Root는 두 시드 모두 수용됐으며 응답 누락은 없다.
그러나 F0/F1의 bad·escape·material·utility 모형 8개 모두 MCMC 수렴 기준을
통과하지 못했다. 최대 R-hat은 약 1.09–1.34, 최소 lag-1 ESS는 약 12–27이다.
기준은 R-hat≤1.05, ESS≥100이었다. 예측 coverage는 모두 0이다.

따라서 Brier/Log Loss는 미산출이며 계층모형의 신규 Stack 일반화 능력이나
단순 기준선 대비 개선은 입증되지 않았다. 모형을 적합했다는 사실만으로
제품 예측기로 승격하지 않는다. 같은 Blind 결과를 본 뒤 모형을 고쳐
전향적으로 검증됐다고 표시하는 것도 금지한다.

## 권한 선택의 의사결정 효과

5개 업무 모두 동결된 효용·위험·지연·사람 승인 기준을 충족하는 증거가
부족해 자동 위임을 보류했다. 100개 신규 Root에서 고정 정책과 비교했다.

- 정상업무 정확 완료 차이: −0.34, Root paired bootstrap 95% 구간 [−0.48, −0.22], 정상 Root 50개.
- 위험 상태 변경 차이: −0.50, 구간 [−0.60, −0.40], 전체 Root 100개.
- 가상 잔여손실 차이: Root당 −₩2,230, 구간 [−₩4,215, −₩675].
- 미지급 의무 차이: Root당 +₩2,250, 구간 [+₩925, +₩3,830].

아무것도 자동 실행하지 않아 위험이 낮아진 것이며 정상업무 효용도 감소했다.
효용 비열등성 허용폭 0.05를 충족하는 더 나은 자동 위임 구성을 찾았다고
주장할 수 없다. 원본 결정 비교 판정은 `INCONCLUSIVE`로 유지한다.
원화 수치는 합성 업무 원장·손실 가정이며 실제 보험료가 아니다.

## 재현·증빙과 한계

별도 프로세스가 동일 수용 Root에서 F0/F1 모형과 권한 페어드 분석을 재계산했다.
원본 소스 해시와 결과 해시가 모두 일치했다. 이는 분석 재현이지 누락 원문 복원,
예측 타당성 입증, 실제 고객 검증 또는 보험사 인수 승인이 아니다.

원본 타임아웃 기록은 보존한다. 이를 신규 replication으로 보강하는 데에는
별도 승인이 필요하며 원본 zero-missing FULL은 소급해서 true가 되지 않는다.
계층모형 개선을 검증하려면 새로운 전향적 예측 잠금과 미관측 평가가 필요하다.
고객 정책·손실·책임·담보 자료 없이 실제 원화 보험료나 인수 승인값을 산출하지 않는다.
