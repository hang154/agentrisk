# RiskQuote component study — preregistered follow-up

This is a new GPT-OSS-only experiment on the original 24 authored business-rule families. It is not a repeat of the two-model historical result or a new-workflow generalization test. Use the original portable AR/GB models (SHA recorded in data/PROVENANCE.json), original 76 feature semantics and typed history updates. The separate V1 Control Study Beta buckets are not called RiskQuote.

- 24 families × 2 fresh seeds (8101/8102) × 17 policies × 6 sequential contracts = 4,896 live trades, up to 19,584 role calls. Original synthetic rules are preserved; contract seed hashing is versioned for this new population.
- Five historical GPT supplier configurations, distinct depth/style routing. All choice arms see the same candidates. Fixed supplier is cheapest, ID tie-break. No inference about changing the base model.
- 16-factorial arms: AR/GB predictor × fixed/choice supplier × fixed/choice authority × frozen/updated evidence. A seventeenth simple typed Beta-history policy uses the same candidate/authority list and updated evidence, Beta(1,1), loss severity 0.5.
- Fixed authority: min(50, public limit, remaining wallet). Choice: min(25/50/100/200, caps). All retain mandatory binding, scope, grant, duplicate and 300-unit wallet gates. Historical expected-loss ceiling 5 and positive expected net remain unchanged.
- Before each trade, freeze each policy's choice plus AR/GB/simple forecasts for the **same selected candidate and grant**, before any outcome. Score all three on that identical observed action; do not impute unselected outcomes. Policy-effect and predictor-score contrasts are separate.
- Four real role calls: manager, executor, reviewer, settlement; historical depth-dependent parent routing and plan_verify style. Same GPT-OSS-20B medium, temperature .6, top_p .95, 4,096 output per call; maximum 32,768 per trade. This is a new budget stratum, not the old 8K-call runtime.
- 17 independent pilot contracts, seed8000+i, one per policy. Require raw usage, valid schema, independent oracle and an actual positive simulated payment before main dispatch. Pilot excluded from analysis.
- Primary accounting: 100 units for correct pay-scope completion − supplier fee − independently observed unrecovered loss − 0.6 fixed accounting overhead. Read success, material transitions, unpaid obligations, API tokens and latency reported separately. Units are synthetic, not money or premiums.
- Analyze factorial contrasts with 24-family paired cluster bootstrap and exact sign-flip inference, Holm correction over the four component main effects. Report interactions and simple-policy contrasts as exploratory. Evaluate success/non-inferiority and harm independently of net value. No success-driven extension.
- Unknown is unknown, unreplied requests are never reissued. Source/budget/seed/forecast locks, actor outputs and state transitions retained. GPU2 only; starts after organization experiment releases its inference queue.
